# TORGEX — Торговое оборудование

Полнофункциональный сайт для магазина торгового оборудования.

## 🎯 Функциональность

✅ **Каталог товаров** - 13 товаров в разных категориях  
✅ **Фильтрация** - по категориям, наличию, цене  
✅ **Поиск** - по названию и категории  
✅ **Корзина** - с сохранением в localStorage  
✅ **Интеграция WhatsApp** - быстрое оформление заказов  
✅ **Модальные окна** - для просмотра деталей товаров  
✅ **Адаптивный дизайн** - работает на всех устройствах  
✅ **Dark mode** - современный тёмный интерфейс

## 🚀 Быстрый старт

### Локально

1. Клонируй репозиторий:
```bash
git clone https://github.com/Khizrievw123/torgex-store.git
cd torgex-store
```

2. Открой `index.html` в браузере (или используй Live Server)

### На GitHub Pages

1. Перейди в `Settings` → `Pages`
2. Выбери ветку `main` как источник
3. Сайт будет доступен по адресу: `https://khizrievw123.github.io/torgex-store/`

## 🛠️ Технологии
